# RightWake v0.1.0

Initial preview of the Rust work-event bridge: verified provider events, explicit ownership of existing work threads, local context directory, durable jobs and drafts, native CLI, local MCP/plugin package, and self-hosted deployment preparation.

The release workflow assembles native macOS/Linux archives for arm64 and x86_64 with `SHA256SUMS`. Its platform jobs exercise local tests, socket fixtures, and installer smoke. A successful main-branch CI run may automatically publish this experimental prerelease only from its exact tested commit and only when the package version has not already been released. Its jobs do not establish real Codex model continuation, authorized real-provider writes, or a live relay/container deployment. Separately, Codex CLI 0.166.0 installed the local marketplace plugin in an isolated empty profile, and the cached package's MCP launcher passed local protocol/setup/status checks without a model turn.

Read [the acceptance ledger](https://github.com/Nunchakus888/right-wake/blob/v0.1.0/docs/acceptance.md) before relying on an integration. Drafts require independent approval; no new work conversation is created automatically. Existing Codex targets require a verified supported host and exclusive writer conditions.

Install from the attached `install.sh` with `--version v0.1.0`, or extract the matching archive after checking `SHA256SUMS`. The default native install needs no Node.js, Python, Docker, Rust, or sudo. Configuration and data are preserved by service uninstall.
